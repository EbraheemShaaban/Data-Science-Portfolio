Titanic Survival Prediction Using Machine Learning

Project Overview

This project applies supervised Machine Learning classification algorithms to predict whether a passenger survived the Titanic disaster based on available passenger information.

The project covers data exploration, preprocessing, feature scaling, model training, performance evaluation, hyperparameter tuning, and cross-validation.

Project Objectives

Explore and understand the Titanic dataset.

Handle missing values and remove unnecessary columns.

Encode categorical features for model training.

Split the dataset into training and testing sets.

Train and compare classification algorithms.

Evaluate model performance using classification metrics.

Optimize Logistic Regression using GridSearchCV.

Assess model performance using cross-validation.
