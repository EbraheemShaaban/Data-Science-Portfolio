# Data-Science-Portfolio
Boston Housing Price Prediction

Project Overview

This project uses Machine Learning regression algorithms to predict housing prices based on available housing-related features. The goal is to explore the dataset, train regression models, compare their performance, and improve model accuracy through hyperparameter tuning.

Objectives

Explore and understand the housing dataset.

Perform basic data analysis and visualization.

Build and compare regression models.

Evaluate model performance using appropriate metrics.

Optimize the Random Forest model using GridSearchCV.

Evaluate model generalization using cross-validation.

Technologies Used

Python

Pandas and NumPy

Matplotlib and Seaborn

Scikit-learn

Jupyter Notebook
